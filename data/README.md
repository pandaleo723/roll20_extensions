# Game data

Generated by `node scripts/build-all.js` from [5etools-cn](https://github.com/tjliqy/5etools-cn)
(2024 Player's Handbook content, 5etools source `XPHB`, plus the 2024 DMG magic items that are in
SRD 5.2, source `XDMG`).

| Folder | Contents | In git? |
|---|---|---|
| `srd/` | SRD 5.2 subset only (entries tagged `srd52`) | ✅ shipped with the extension |
| `local/` | Full 2024 Player's Handbook data, for personal use | ❌ git-ignored — never commit or distribute |

The extension loads `srd/` and, if present, `local/` (local entries override SRD ones with the same id).

## Files

| File | Builder | Records |
|---|---|---|
| `spells.json` | `scripts/build-data.js` | spells |
| `items.json` | `scripts/build-items.js` | weapons, armor, shields, ammunition, foci, tools, gear, mounts, vehicles (XPHB), and the SRD 5.2 magic items of the 2024 DMG (XDMG: potions, scrolls, rings, wands, rods, wondrous items, specific magic weapons/armor; no generic "+1 Weapon" variants, no non-SRD XDMG items) |
| `feats.json` | `scripts/build-traits.js` | feats: `category` = `origin` / `general` / `fightingStyle` / `epicBoon` |
| `backgrounds.json` | `scripts/build-traits.js` | backgrounds + the origin feat they grant (`feat.id` → `feats.json`) |
| `species.json` | `scripts/build-traits.js` | species with `traits` and `lineages` (Drow, Black Dragonborn, …) |
| `class-features.json` | `scripts/build-traits.js` | class and subclass features (flat; `className`, `subclass`, `level`) |

All localized text is `{ en, zh }`. Every record has `id` (`name|source`, lower-case), `srd52`,
`source`, `page`.

**Features & Traits records** (feats, class features, species traits; backgrounds point at their
feat) carry the Roll20 `repeating_traits` fields: `name`, `traitSource` (→ `source`, the sheet's
i18n key: `racial` / `class` / `feat` / `background`), `sourceType` (→ `source_type`, e.g.
"Wizard 3 (Abjurer)", "Elf (Drow Lineage)", "Origin Feat") and `description`.

**Weapons** have `weapon` (dice, `damageType`, `versatileDamage`, `range` {normal, long},
`properties`, `mastery`, `ability`: `str` / `dex` / `str-or-dex`), plus `roll20Properties`
(→ `itemproperties`, English, e.g. "Finesse, Light, Thrown") and `roll20Modifiers`
(→ `itemmodifiers`, Roll20 compendium format, English, e.g. "Item Type: Melee Weapon, Damage: 1d8,
Damage Type: Slashing, Alternate Damage: 1d10, Alternate Damage Type: Slashing"). **Armor/shields**
have `armor` (`ac`, `dexMax`, `strength`, `stealthDisadvantage`) and e.g. "Item Type: Light Armor, AC: 11".
In `srd/`, weapon property rules text (`properties[].description`) is empty: 5etools does not
mark it `srd52`.

Every item has `category` (the picker's chip: `weapon` / `armor` / `ammo` / `gear` / `tool` /
`consumable` / `magic` / `other` = mounts and vehicles) and `magic` (`null`, or `{ rarity,
rarityName, attunement, charges }`). Magic bonuses are added to `roll20Modifiers` in the words the
sheet's workers parse: "Melee Attacks +1, Melee Damage +1", "AC +1", "Saving Throws +1",
"Ability Checks +1", "Spell Attack +2", "Spell DC +2", "Strength: 21". Bonuses that only apply
sometimes (Arrow-Catching Shield, Rod of Alertness) are left out.

### Templates (variable numbers)

Sense ranges are stored as placeholders so the value can be inserted at fill time:

```json
"description": { "en": "You have Darkvision with a range of {darkvision} feet.",
                 "zh": "你拥有 {darkvision} 尺黑暗视觉。" },
"params": { "darkvision": { "default": 60, "unit": "feet" } }
```

`params.<name>.default` is the value this entry grants (Elf 60, Dwarf / Drow lineage 120). To
render, replace each `{name}` with the chosen value (or `default`). Placeholders are
`{darkvision}`, `{blindsight}`, `{tremorsense}`, `{truesight}`; entries without `params` are
plain text. Species also expose the numbers as `senses` (e.g. `{ "darkvision": 60 }`).
