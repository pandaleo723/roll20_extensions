# Game data

Generated by `node scripts/build-data.js` from [5etools-cn](https://github.com/tjliqy/5etools-cn).

| Folder | Contents | In git? |
|---|---|---|
| `srd/` | SRD 5.2 subset only (entries tagged `srd52`) | ✅ shipped with the extension |
| `local/` | Full 2024 Player's Handbook data, for personal use | ❌ git-ignored — never commit or distribute |

The extension loads `srd/` and, if present, `local/` (local entries override SRD ones with the same id).
